Lab Report Maker

Make two PDFs for your lab: (1) a lab report with each task's code and its real output, and (2) an Algorithms, Pseudocodes & Dry Runs file from photos of your handwritten work. Everything runs in your browser and nothing is uploaded anywhere.

Shared settings: the Title page and Formatting sections below apply to both PDFs (the lab report and the Algorithms, Pseudocodes & Dry Runs file), so they always match.

Title page · used by both PDFs

Formatting · theme and layout apply to both PDFs

Syntax highlighting colours the code in the lab report (keywords, strings, comments, numbers and so on). Picking a highlighting theme also sets the code box background to match it; the output box is not changed.
